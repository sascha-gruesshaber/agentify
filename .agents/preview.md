# Preview — seeing a screen before and after a change

**NOT CONFIGURED — no user interface.** This repository ships markdown skills, agent definitions and
three Node tools; there is no app to start and no screen to photograph. `/deliver` skips every screens
step and says so once per run.

`show`'s page and walkthrough templates are HTML, but they are checked by `check-page.mjs` in the gate,
not by screenshots. If this repo ever grows a UI, `/onboard` fills this file in.
